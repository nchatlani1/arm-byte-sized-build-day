# CrowPanel Companion

Version 0.3.2 reads permitted calendar/Spotify data and sends metadata to the
Morning Briefing project's optional extensions over USB or encrypted BLE.
Layouts, controls and uploading stay in the participant project. Closing settings
keeps the menu-bar/tray app running; startup is opt-in and retries back off when idle.

[Downloads and setup](../guides/COMPANION-SETUP.md#downloads) ·
[Build on the target OS](../guides/BUILD.md)

No app is needed for the default offline or direct Wi-Fi stock/weather screen.
The current support release excludes legacy full-frame preview/server experiments.
