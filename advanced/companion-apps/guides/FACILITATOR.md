# Facilitator checks

Start with Morning Briefing: ARM, ZIP 92128, no account or companion. Preinstall
PlatformIO and verify default offline upload/display. Participants personalize
ticker and ZIP; custom ZIPs need one build-time lookup. DEMO is not a live quote.

For optional integrations, open advanced/display, build/upload its firmware, then connect
the app. Verify physical USB/BLE pairing, valid calendar/Spotify data, stale-data
indication, power-cycle reconnect, OS sign-in launch, pause and absent-display
energy behavior on each target OS. Report untested cases explicitly.
The Mac download is an ad-hoc pilot; Windows/Intel need target builds and pilots.
