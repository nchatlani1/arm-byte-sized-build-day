# Live data

Stock/weather runs directly on the board with approved Wi-Fi configured in the
participant .env. Use its live build/upload tasks. Check Wi-Fi/IP, time/TLS,
provider result and physical LIVE screen separately.
Calendar and Spotify use optional companion extensions in that advanced/display project.
See [the companion guide](COMPANION-SETUP.md). Keep tokens and passwords private.
