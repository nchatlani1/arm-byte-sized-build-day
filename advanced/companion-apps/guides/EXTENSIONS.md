# Advanced projects

Start with `starter/` for one stock/weather screen. For calendar or Spotify, open
`advanced/display/` and upload its firmware. Both flags are enabled there by
default. The starter has no account receiver. Companion app source/build tools live
in `advanced/companion-apps/` in this same repository.

[Settings, downloads, connection and Codex prompts](COMPANION-SETUP.md).
The previous four-screen example is historical only and is not a current download.
